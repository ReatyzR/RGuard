## 🇬🇧 English

### Overview
**RGuard** is a lightweight, high-performance Anti-Crash and Exploit protection plugin designed specifically for Spigot 1.8.9 servers. It protects your server against packet spam, invalid NBT payloads, and common crash exploits without dropping TPS.

### ✨ Features
* 🚫 **Packet Spam Protection:** Filters out invalid or spammy network packets (e.g., CustomPayload).
* 📦 **NBT Crash Fix:** Detects and blocks malicious or oversized NBT data.
* 📍 **Invalid Movement / Position Check:** Rejects invalid player position and movement packets.
* ⚡ **High Performance:** Uses lightweight/async packet listening to maintain 20 TPS.
* ⚙️ **Fully Configurable:** All alert messages and rules are customizable via `config.yml`.

### 🚀 Installation
1. Download the latest `.jar` from the [Releases](../../releases) section.
2. Place it into your server's `plugins` folder.
3. Restart your server.
4. Customize settings in `plugins/RGuard/config.yml`.

## 🇹🇷 Türkçe

### Genel Bakış
**RGuard**, Spigot 1.8.9 sunucuları için özel olarak geliştirilmiş, hafif ve yüksek performanslı bir Anti-Crash ve Exploit koruma eklentisidir. Sunucu performansınızı (TPS) düşürmeden zararlı paket bombardımanlarını, hatalı NBT verilerini ve yaygın çökertme yöntemlerini engeller.

### ✨ Özellikler
* 🚫 **Paket Spam Koruması:** Geçersiz veya aşırı hızlı gönderilen ağ paketlerini (CustomPayload vb.) anında filtreler.
* 📦 **NBT Crash Koruması:** Sunucuyu düşürmeye çalışan işlenmemiş veya devasa NBT verilerini engeller.
* 📍 **Geçersiz Pozisyon Kontrolü:** Hatalı koordinat ve hareket paketlerini reddeder.
* ⚡ **Yüksek Performans:** Sunucu TPS değerini etkilemeyen ultra hafif paket dinleme altyapısı.
* ⚙️ **Tamamen Özelleştirilebilir:** Tüm uyarı mesajları ve kurallar `config.yml` üzerinden ayarlanabilir.

### 🚀 Kurulum
1. En son `.jar` dosyasını [Releases](../../releases) sayfasından indirin.
2. Dosyayı sunucunuzun `plugins` klasörüne atın.
3. Sunucunuzu yeniden başlatın.
4. `plugins/RGuard/config.yml` dosyasından ayarlarınızı yapılandırın.
